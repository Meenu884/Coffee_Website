# BeanStreet Coffee Website

A simple coffee shop landing website built with HTML, CSS, and JavaScript.

## Project Overview

BeanStreet is a coffee-themed website that showcases:

- a home page with featured products
- an about page for the brand story
- a contact page with visit details and a map
- product interactions such as add-to-cart, like buttons, and ratings

## Website Pages

- `cof.html` — main landing page
- `about.html` — brand and branch information
- `contact.html` — contact form and store details
- `cof.css` — shared website styling
- `cof.js` — cart, like, and rating interactions

## Run the Project

Open the site locally using a simple Python server:

```bash
python3 -m http.server 8000
```

Then open:

- `http://127.0.0.1:8000/cof.html`

## Notes

This project is a static website and does not use a backend database.
