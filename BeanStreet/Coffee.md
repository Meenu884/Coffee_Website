# BeanStreet Coffee Website

BeanStreet is a modern coffee shop landing page designed to highlight the brand identity, menu experience, and customer engagement through a clean and responsive web interface.

## Project Overview

This project presents a polished coffee shop website built using HTML, CSS, and JavaScript. It is intended to provide visitors with a visually appealing introduction to the brand while enabling interactive product-related actions such as likes, ratings, and add-to-cart behavior.

## Core Features

- A welcoming homepage with featured coffee offerings
- An about section that communicates the brand story and business identity
- A contact page with store details and a map integration
- Interactive UI elements for customer engagement and browsing experience

## Website Structure

- `cof.html` — primary landing page
- `about.html` — brand information and business overview
- `contact.html` — contact details and visitor support information
- `cof.css` — shared styling and layout design
- `cof.js` — front-end interactivity including cart and rating functions

## Running the Project Locally

To launch the website locally, use a simple Python HTTP server:

```bash
python3 -m http.server 8000
```

Then open the homepage in your browser:

- `http://127.0.0.1:8000`

## Technical Notes

BeanStreet is implemented as a static website and does not require a backend database or server-side processing for its current functionality.
